# BB_score_site

Hi everyone!

BB scores is a basketball scoreboard management system that will help you to keep track of all friendly and professional matches. No matter how intense the play is, BB scores will help you out.

Just open the site, start a new match, fill in the details, and you are done!
A  few simple steps to give you the ultimate satisfaction. 

This is an ongoing project, so many of the features are still in development. By all means, I would love to hear suggestions on the website on my LinkedIn handle. Simply search for Parth N Bhosale or visit my GitHub profile.
